# Contributing

Bug reports, feature requests, and security reports are welcome.

Please do not submit code or documentation changes unless the repository owner
has explicitly invited the contribution and completed a separate contributor
agreement with you. This protects both sides and keeps the ownership needed to
offer separate commercial licenses.

Opening an issue does not transfer ownership of your idea or grant permission to
use confidential information. Never include secrets, credentials, private user
data, or unpublished security details in a public issue.

For a security vulnerability, use GitHub's private vulnerability reporting once
it is enabled. Until then, contact the repository owner privately instead of
opening a public issue.
