aBitBetterKeyboard is an AI-powered iPhone keyboard for 64 languages.

Fix spelling and grammar, rewrite a sentence, choose a tone, create a reply to a message you copied, or dictate without leaving your workflow.

Choose the languages you type in, then switch with a swipe across the space bar or the globe key. Where Apple provides a system dictionary, on-device spelling suggestions help as you type. Emoji, a personal dictionary, and customizable key layouts are built in.

Cloud AI is off by default and is available only to adults 18 or older. Cloud features send only the text or audio needed for the action after you choose that action and allow cloud processing. Nothing is sent while you type.

Typing, suggestions, emoji, and local customization work without cloud AI. Add aBitBetterKeyboard under Settings > General > Keyboard > Keyboards to use it in other apps. Full Access is needed for shared settings, key clicks, and cloud features.
